# 安全性の指摘のパケット（行動確認用）

review-fix-planning が、安全性の影響を持つ指摘の重大度をどう再評価し、採否を決めるかを確かめるための、架空の PR の事実の集まりである。行動確認では、新しいコンテキストのエージェントに、スキルとこのパケットだけを読ませて回答させる。旧版の採点は `validation.md`、新3結果の採点は `2026-10-08-rework.md` にあり、このパケットには含めない。

## 回答者への指示

あなたは review-fix-planning を実行する planner である。下の事実はすべて、あなたが手順どおりに確かめ終えたものとして扱う（git・gh・ファイルの追加の確認は不要で、実行もしない）。スキルの手順と規則だけに従い、日本語で回答する。ファイルを作成・編集しない。
